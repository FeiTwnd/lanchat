本文档逐条列出本项目全部测试用例，共 **74 条**：单元测试 **47 条**、集成测试 **7 条**、
组件级界面校验 **6 条**（本轮执行，把界面组件离屏渲染成 PNG 后做像素断言与截图核对）、
窗口级界面走查 **14 条**（上一轮在 Xvfb 虚拟显示中由 `java.awt.Robot` 驱动真实窗口执行所得的快照结论，**本轮未重跑**）。
表中"实际结果"与"是否通过"两列取自真实运行输出，未做任何修饰；凡未实际执行的项均明确标注"未执行"或"未自动化覆盖"，不以推测值填充。

## 一、编号规则与判定口径

| 项目 | 说明 |
| --- | --- |
| 用例编号 | 单元测试：`UT-<模块>-<序号>`；集成测试：`IT-<序号>`；组件级界面校验：`UI-<序号>`；上一轮窗口级界面走查：`UIH-<序号>` |
| 模块缩写 | `SEC` 密码安全工具；`DAO` 用户数据访问；`SVC` 用户业务服务；`MSG` 消息与持久化；`FILE` 文件传输；`IT` 端到端集成；`UI` 组件级界面校验（本轮）；`UIH` 窗口级界面走查（上一轮快照） |
| 用例名称 | 与源码中 `@Test("...")` 注解文本完全一致，便于与运行输出逐行核对（界面类一项对应离屏渲染程序或走查程序中的一条断言） |
| 执行方式 | 单元测试由 `TestRunner` 反射执行（方法名字典序）；集成测试由 `IntegrationTest.main` 顺序执行；组件级界面校验由离屏渲染程序在 Xvfb 中执行（不启动服务器与窗口管理器）；窗口级界面走查由走查程序在 Xvfb 中顺序执行 |
| 通过判定 | 用例内全部断言成立即通过；任一断言抛出 `AssertionError` 即失败 |
| 不稳定判定 | 同一份代码多次复跑出现"通过/失败"不一致者，判定为不稳定，按未通过计入 |
| 数据快照 | 2026-09-19，JDK 21.0.12，Ubuntu 24.04.4 LTS，测试网络为本机回环 127.0.0.1；组件级界面校验与窗口级走查在同一环境下完成 |
| 数据隔离 | 存储只保留数据库后，单元测试与集成测试统一使用独立测试库 `lanchat_test`（由 `TestDatabase` 把连接地址中的库名替换得到，并加 `createDatabaseIfNotExist=true`），每个用例开始前清空 `chat_user` 与 `chat_message`；可用系统属性 `lanchat.test.db.url` 覆盖为其他库（如并行开发时各任务使用各自的库）。接收文件与导出文本仍写临时目录隔离 |

## 七、运行命令

### 7.1 IntelliJ IDEA（推荐）

1. `Build → Rebuild Project` 编译全部源码，输出目录为 `out/production/LANChat` 与 `out/test/LANChat`；
2. 直接运行仓库自带的运行配置（位于 `.idea/runConfigurations/`）：

| 运行配置 | 主类 | 说明 |
| --- | --- | --- |
| 单元测试（47 用例） | `com.chat.test.TestRunner` | 反射执行全部单元测试 |
| 集成测试（7 用例） | `com.chat.test.IntegrationTest` | 自行启动服务器与多个客户端 |
| 服务器（图形控制台） | `com.chat.server.ChatServer` | 唯一的服务器启动方式 |

上述运行配置的工作目录都必须设为项目根目录，否则 `config/chat.properties` 与 `data/` 会定位失败。
运行服务器与测试前需把 MySQL Connector/J 驱动加入项目依赖（`lib/mysql-connector-j-8.2.0.jar`），否则 DAO 会报告"未找到 JDBC 驱动"；
测试默认使用独立测试库 `lanchat_test`，需要隔离到其他库时用系统属性 `lanchat.test.db.url` 覆盖。

### 7.2 命令行

```bash
# 编译（在项目根目录执行；主源码只使用 java.sql 标准接口，编译期不依赖驱动 jar）
javac -encoding UTF-8 -d out/production/LANChat $(find src/main/java -name '*.java')
javac -encoding UTF-8 -cp out/production/LANChat -d out/test/LANChat $(find src/test/java -name '*.java')

# 单元测试（47 条）：运行期需要 JDBC 驱动，默认连接独立测试库 lanchat_test
java -cp out/production/LANChat:out/test/LANChat:lib/mysql-connector-j-8.2.0.jar \
     com.chat.test.TestRunner

# 集成测试（7 条）
java -cp out/production/LANChat:out/test/LANChat:lib/mysql-connector-j-8.2.0.jar \
     com.chat.test.IntegrationTest

# 需要指向其他测试库时（例如并行开发时各任务使用各自的库）增加系统属性覆盖
java -Dlanchat.test.db.url='jdbc:mysql://localhost:3306/lanchat_verify?useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true' \
     -cp out/production/LANChat:out/test/LANChat:lib/mysql-connector-j-8.2.0.jar \
     com.chat.test.TestRunner
```

退出码约定：0 表示全部通过，非 0 表示存在失败用例，可直接被 IDE 运行配置、脚本或持续集成判断。

界面校验不通过任何脚本提供入口（离屏渲染程序与走查脚手架都只用于取证，不属于交付源码）。本轮执行的是组件级离屏渲染校验：
程序把界面组件渲染成 PNG 归档并输出选中行的像素统计，据此判定橙色 `#E95420` 为 0 像素、浅蓝 `#CFE9FA` 超过 2000 像素，
逐项输出断言结果与截图文件名；上一轮的窗口级走查程序已不在仓库中，其 14 项结论作为历史快照保留在 5.2 节。
